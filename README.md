# interactive_bezier_curves
Interactively mess with Bezier curves, like moving the control points, changing the order of the Bezier curve, and changing the resolution of the drawn Bezier curve.

Uses a [custom piece of code](https://github.com/masademan/tkinter_text_tag_formatting) I made to make it easy to format text in tk.Text objects with tags. 

Code for Windows compiled with "pyinstaller -F main.yp --noconsole" \
Code for MacOS compiled on GitHub with .github/workflows/build.yml
