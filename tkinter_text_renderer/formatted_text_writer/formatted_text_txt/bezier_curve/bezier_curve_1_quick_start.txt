[H1]Program function[H1/]
This program is to interactively generate any order Bezier curve given some number and position of control points.
This program was creation was just a sudden burst of motivation after talking about Bezier curves in a math class, so now enjoy this program [STRIKETHROUGH]modern art generator[STRIKETHROUGH/]

[H1]UI basics[H1/]
The UI is split into 2 main parts, the canvas where the stuff is drawn, and the controls where you can change different settings that change the canvas.

The canvas takes up most of the window and it shrinks or grows to take up as large of a space in the window as possible. So for larger curves, a larger window is recommended, since the canvas would grow accordingly.

The controls take up a maximum width and sit on the right of the window. And within the controls, there are 4 main sections signified by the gray boxes.
The sections are labeled in bold "Grid settings", "Control point settings", "Bezier curve settings", and "Help".
Each section contains controls for the respective name, so there are settings for the Bezier curve rendering in the "Bezier curve settings" section, etc.
And at the bottom of the controls, there are 2 buttons, "Reset" and "Quit". Pressing the "Reset" button makes all the settings you changed reset to the default, and the defaults are just what the settings were when the window first opened. And pressing the "Quit" button closes the program.


[H1]Control point basics[H1/]
The control points are the red circles in the canvas. These are what can be moved and are what dictate the shape of the Bezier curve.

To move the control points, just click one of them and drag it. Holding control while dragging makes it snap to the grid at different intervals (1/2 of grid unit by default). This interval can be changed (discussed in a different guide).
Holding shift while dragging makes the point move either completely horizontally or vertically.
Holding control and shift while dragging combines these effects.

Another way to move control points is to right click one of them and use the arrow keys to move the points by different intervals (1/4 of grid unit by default). This interval can be changed (discuss in a different guide).


[H1]Bezier curve basics[H1/]
The blue collection of lines is the Bezier curve being drawn. This is the fancy thing you wanted to use the program to draw.

The curve is affected by the positions of the control points, so that's not able to be changed. But some things that can be changed are the curve resolution, linewidth, and whether or not to show the sampled points.

The way the curve works is by sampling points from the "true" Bezier curve and then drawing straight lines between the sampled points. So the curve resolution affects how many points are sampled. In simpler terms, lower resolution means a rougher curve. Higher resolution means a [ITALIC]smoother[ITALIC/] curve. This setting can be adjusted in the number input with the text "Curve resolution" above it.

The linewidth is just how [BOLD]THICC[BOLD/] to make the drawn curve. So a higher linewidth makes it thicker, and a lower linewidth makes it thinner. This setting can be adjusted in the number input with the text "Curve linewidth" above it.

As mentioned earlier, the curve is generated by sampling a bunch of points from the "true" Bezier curve, and there's a setting to show these sampled points. It can be turned on using the checkbox with the text "Show sampled points" next to it.
"""
